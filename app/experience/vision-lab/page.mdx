# Vision Lab @ GWU

Advised by Dr. Robert Pless, working on using multimodal data for camera calibration and contrail detection.

- Curated a dataset of 4K live webcams for real-time analysis.
- Built a scalable image search system using CLIP embeddings, Express.js, Redis, and PostgreSQL.
- Developed a camera calibration pipeline to project aircraft GPS coordinates into image space for contrail detection.
